Программа для работы с треугольником  
  Программа на С++ для проверки вычисления периметра треугольника, 
  площади по формуле Герона и определения равнобедренности  
  
  Запуск на Linux:
    ./Triangle
  
Использование  
  Введите три целых числа - стороны треугольника. Пример:  
	Введите стороны треугольника a, b, c:  
    5 5 8  
    Периметр: 18  
    Площадь по формуле Герона: 12  
    Треугольник равнобедренный  
  
Особенности  
  Работает только с целыми сторонами.  
  Площадь округляется вниз из-за типа int.
