# Программа для вычисления Длинs окружности/Площадb окружности/Площадb сектора окружности
## условие работы программы
1) сначало надо ввести значения радиуса,а потом угла
2) вводить можно только цифры,текстовый тип данных не рассматривается
3) программа может работать с не целочисленными типами данных
